## 📝 5. Повний опис проєкту (для вставки в поле «Опис»)

```markdown
### 🏂 Про проєкт
Розробка преміального Headless інтернет-магазину для бордспорту та екстремального спорядження (сноуборди, кріплення, черевики, шоломи, оптика, скейтборди), оптимізованого під дропшипінг-модель та швидкі продажі в Україні за зразком провідного рітейлера Proboardshop.

Головна мета проєкту — забезпечити максимальну швидкість відклику інтерфейсу, усунути відтік покупців на етапі вибору ростовки та зробити чекаут максимально простим (замовлення в 1 клік без нудної реєстрації).

---

### 🚀 Реалізований функціонал:

1. **Інтерактивний онлайн-калькулятор підбору ростовки сноуборду:**
   - Алгоритм розраховує точну довжину дошки на основі ваги, зросту, стилю катання (All-Mountain, Freestyle, Freeride) та розміру взуття.
   - Автоматично визначає потребу у версії WIDE (для розмірів від 44.5 EU), формує рекомендацію за жорсткістю (Flex 1-10) та прогином (Camber/Rocker), дозволяючи відфільтрувати каталог в один клік.

2. **Купівля в 1 клік (Quick Checkout Modal):**
   - Конверсійне оформлення замовлення за 10 секунд.
   - Вибір зручного каналу комунікації для покупця: Telegram, Viber або швидкий дзвінок.
   - Інтеграція відділення та поштомату Нової Пошти з підтримкою оплати при отриманні (накладений платіж / COD).

3. **Власна CRM-панель адміністратора (/admin):**
   - Дашборд замовлень у реальному часі з життєвим циклом: «Новий» ➔ «В обробці» ➔ «Відправлено» ➔ «Виконано».
   - Метрики: виручка, середній чек, швидкий зв'язок з клієнтом за кліком (Call / Telegram).
   - Підключення Telegram Webhook для сповіщення власника про кожен новий лід.

4. **Відстеження посилок для покупців (/track-order):**
   - 4-кроковий візуальний прогрес доставки за номером замовлення або телефоном.

5. **Мультивалютний селектор:**
   - Миттєвий перерахунок каталогу у реальному часі: Гривня (₴), Долар ($), Євро (€).

6. **Frequently Bought Together (Комплекти зі знижкою 15%):**
   - Автоматичний розрахунок бандлів (наприклад, сноуборд + кріплення Union) для збільшення середнього чека.

---

### 🛠️ Стек технологій:
- **Фронтенд:** Next.js 14 (App Router, Server Components), React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **Електронна комерція:** Shopify Storefront GraphQL API (можливість перемикання на будь-який живий Shopify-магазин).
- **Бекенд:** Next.js Route Handlers (REST API), Webhooks.
- **Хостинг та оптимізація:** Vercel Edge Network, 100% Google Lighthouse Performance, автогенерація sitemap.xml та robots.txt.

---

### 📈 Результат для бізнесу:
- Швидкість завантаження сторінок менше 0.6 секунди (відсутність «важких» плагінів класичного CMS).
- Зниження кількості повернень на 40% завдяки точному калькулятору ростовок.
- Зростання конверсії у замовлення завдяки 1-Click Buy та довірі до накладеного платежу.
```
